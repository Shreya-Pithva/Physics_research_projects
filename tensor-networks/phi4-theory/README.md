# Scalar φ⁴ Theory in (1+1) Dimensions

Tensor-network study of lattice scalar φ⁴ theory using Matrix Product States.

This project was carried out as part of my BS (Research) thesis at the Indian Institute of Science (IISc), Bangalore.

## Methods

- Matrix Product States (MPS)
- DMRG and iDMRG
- VUMPS
- Tangent-space quasiparticle excitations
- TEBD
- TDVP
- Real-time dynamics

## Project contents

This folder contains code, notebooks, numerical results, and documentation related to the project.
