# Quasiparticles and Scattering in the Spin-1 Heisenberg Chain

This project studies elementary quasiparticle excitations in the spin-1 Heisenberg chain using tensor-network methods.

The aim is to construct quasiparticle excitations, form propagating wave packets, and study their real-time dynamics and scattering.

## Methods

- Matrix Product States (MPS)
- VUMPS ground states
- Tangent-space quasiparticle excitations
- Plane-wave quasiparticle states
- Quasiparticle wave-packet construction
- Dispersion relations and group velocities
- TDVP real-time evolution
- Quasiparticle scattering


## Tools

- Python
- TeNPy
- NumPy
- SciPy
- Matplotlib

## Project contents

This folder will contain the code, notebooks, figures, and numerical results used for the quasiparticle calculations and real-time simulations.
