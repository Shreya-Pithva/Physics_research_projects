# Quantum Non-Demolition Measurements

This project studies quantum non-demolition (QND) measurements and repeated measurement protocols.

The aim is to understand how repeated measurements can be used to extract information about a quantum system while minimizing disturbance to the measured observable.

In particular, the project considers QND measurement of a cavity field with an initially unknown photon-number distribution.

## Topics and Methods

- Quantum non-demolition measurements
- Repeated quantum measurements
- Photon-number measurements
- Cavity quantum systems
- Measurement back-action
- Probability distributions and state update
- Numerical simulation of measurement dynamics

## Tools

- Python
- NumPy
- SciPy
- Matplotlib

## Project contents

This folder will contain code, notebooks, figures, and numerical results related to QND measurement protocols.
